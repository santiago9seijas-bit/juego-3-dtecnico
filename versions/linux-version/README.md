Historial completo: [`../CHANGELOG.md`](../CHANGELOG.md)

## Cómo jugarlo

```bash
unzip v.0.2.zip
chmod +x juego_3d_tecnico.x86_64
./juego_3d_tecnico.x86_64
```

- El ejecutable trae el `.pck` **embebido**: no necesita archivos adicionales.
- Si tu escritorio no lo abre con doble clic, dale permiso de ejecución con el comando de arriba.
- Renderizado: **Forward+ (Vulkan)** — requiere drivers Vulkan (Mesa/AMD/Intel/NVIDIA).
