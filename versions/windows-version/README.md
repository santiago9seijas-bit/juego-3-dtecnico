Historial completo: [`../CHANGELOG.md`](../CHANGELOG.md)

## Cómo jugarlo

1. Descarga y **descomprime** el ZIP.
2. Haz **doble clic** en `juego_3d_tecnico.exe`.

- El ejecutable trae el `.pck` **embebido**: no necesita archivos adicionales.
- Renderizado: **Direct3D 12** — Windows 10/11 con GPU compatible.
- Si Windows SmartScreen avisa al abrir, dale a **Más información → Ejecutar de todos modos** (es un ejecutable sin firma digital, generado localmente con Godot).
